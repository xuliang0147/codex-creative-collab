# 剪辑标准接入

剪辑标准独立维护在 [codex-video-editing-skills](https://github.com/xuliang0147/codex-video-editing-skills)，不把标准复制成多个互相漂移的版本。

安装该仓库的 `creative-video-editing` skill 后，在各产品编导和剪辑任务规则中增加：

> 涉及视频剪辑、返修或参考片复刻时，先读取本机 `creative-video-editing/SKILL.md` 并遵循其验收要求。不同产品共享质量标准，但不共享产品任务历史、素材选择或执行任务。不得把普通口播加普通字幕称为参考效果复刻。保留原声和原版本；字幕效果、贴纸、音效、BGM、节奏以及真实预设使用情况必须有可核对证据。用户未要求发布时只交付审核，不代发平台。

具体 skill 安装位置取决于本机 Codex 配置，不在此仓库写死个人用户目录。

当前后端不自动下载、更新或注入该 skill。规则加载、原生剪辑工具的授权、参考片理解和成片质量需要执行任务实际完成。ffprobe/文件哈希验证只能证明技术条件，不能代替观看与试听。

需求单应记录本次要求的版本数、是否先预览、是否允许付费生成、交付渠道及是否发布；共享标准不能覆盖用户最新要求。现有后端仍有至少两条有效成片的旧门槛，单条需求需另行调整该契约，不能临时造一条假文件过关。
